# 🌞 Solar Power Generation Prediction

A machine learning project that predicts **solar power generation** using environmental and time-based factors. This project applies regression techniques, exploratory data analysis, and model optimization — with a deployed **Streamlit web app** for real-time predictions.

### 🌐 Live Demo  
👉 **Streamlit App:** https://solar-power-generation-2jcmmsfw6ftjhqzs7xwf5b.streamlit.app/

---

## 📌 Project Overview

This project focuses on forecasting solar power generation using weather-based features such as:

- **Temperature**
- **Humidity**
- **Wind Speed**
- **Sky Cover**
- **Time-based parameters** (hour, day, etc.)

The goal is to build a reliable, real-time prediction system for potential use in **renewable energy management**.
